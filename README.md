## 📂 Proyectos Destacados

### 🌿 BioPlant
🔗 Repositorio: https://github.com/BeykelDaniel/BioPlant

Descripción técnica
- BioPlant es una aplicación web construida sobre Laravel (PHP 8.2, Laravel 12) que actúa como un "universo botánico": blog de contenidos, red de usuarios, soporte experto y un market de esquejes.
- La UI está implementada con plantillas Blade y estilos modernos con Tailwind CSS + Vite para un flujo de desarrollo rápido y optimizado.
- Empleo de componentes Blade reutilizables (ej. tarjetas de blog, navbar, componentes de UI) para mantener una estructura clara y mantenible.
- Flujo de rutas en Laravel que entrega vistas server-side; el proyecto incluye scripts para desarrollo y despliegue (`composer` scripts y `npm` scripts) y migraciones para la base de datos, lo que permite ejecutar un entorno local reproducible.

Stack / etiquetas
- `PHP 8.2` • `Laravel 12` • `Blade` • `Tailwind CSS` • `Vite` • `Eloquent ORM` • `npm` • `Vite`

Buenas prácticas destacadas
- Performance: uso de Vite para builds rápidos y optimizados; `npm run build` para producción.
- Diseño responsive: clases Tailwind y layout grid adaptativo (ej. grid de artículos y secciones adaptativas).
- Accesibilidad: estructura semántica en vistas Blade (etiquetas Hn, roles claros) y texto alternativo en recursos multimedia (vídeo con fallback).
- Arquitectura limpia: separación de rutas, vistas y componentes; scripts `composer` para setup y migraciones reproducibles.

Por qué destaca
- Buena base para proyectos full-stack con server-side rendering y componentes front.
- Pensado como producto: blog, sección de vendedores/esquejes y módulos de soporte para usuarios.

### 🛍️ Tenderete — Proyecto Intermodular
🔗 Repositorio: https://github.com/BeykelDaniel/Tenderete--Proyecto-Intermodular

Descripción técnica (resumen basado en la estructura del repositorio)
- Tenderete es un proyecto intermodular con vistas en Blade que implementa un sistema tipo marketplace/gestión de puestos — un entorno pensado para gestionar puestos/ventas locales o eventos tipo “tenderete”.
- La presencia de plantillas Blade y un repositorio de tamaño significativo sugiere una arquitectura con varios módulos (vistas, controladores y assets) organizada para soportar múltiples roles (administrador, vendedor, usuario final).
- Orientado a SSR con Laravel (Blade) y diseño de páginas server-side, probablemente complementado por assets JS/CSS para interacción y formularios de gestión.

Stack / etiquetas
- `Laravel (Blade)` • `PHP` • `Blade templates` • `Arquitectura intermodular` • `SSR`

Buenas prácticas destacadas (observadas/implícitas)
- Organización por módulos: facilita mantener responsabilidad separada entre vistas y lógica de negocio.
- Enfoque en usabilidad y flujo multi-rol (vendedores/administradores/usuarios).
- Plantillas Blade permiten una renderización eficiente del lado servidor y control fino de carga de assets.
